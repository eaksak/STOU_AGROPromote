# คลังข้อสอบประมวลสาระ หน่วยที่ 03: แนวคิด ทฤษฎีที่เกี่ยวข้องกับการส่งเสริมและพัฒนาการเกษตร (จำนวน 50 ข้อ)

### ข้อที่ 301: เจ้าของทฤษฎีการแพร่กระจายนวัตกรรม (Diffusion of Innovations)
- **ก.** เดวิด เบอร์โล (David Berlo)
- **ข.** เคิร์ต เลวิน (Kurt Lewin)
- **ค.** มัลคอล์ม โนว์ลส์ (Malcolm Knowles)
- **ง.** เอฟเวอเรตต์ เอ็ม. โรเจอร์ส (Everett M. Rogers)
- **จ.** เอบราฮัม มาสโลว์ (Abraham Maslow)

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เอฟเวอเรตต์ เอ็ม. โรเจอร์ส (Everett M. Rogers)

### ข้อที่ 302: กลุ่มผู้ยอมรับนวัตกรรมกลุ่มแรกสุด (2.5%) ตามแนวคิดของโรเจอร์ส
- **ก.** กลุ่มผู้นำการเปลี่ยนแปลง
- **ข.** กลุ่มยอมรับเร็ว
- **ค.** กลุ่มยอมรับช้า
- **ง.** กลุ่มล้าหลัง
- **จ.** กลุ่มนวัตกร (Innovators)

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร กลุ่มนวัตกร (Innovators)

### ข้อที่ 303: กลุ่มผู้ยอมรับที่เป็น 'ผู้นำทางความคิด' (Opinion Leaders) ในชุมชน (13.5%)
- **ก.** กลุ่มผู้นำการเปลี่ยนแปลง / ยอมรับเร็ว (Early Adopters)
- **ข.** กลุ่มนวัตกร (Innovators)
- **ค.** กลุ่มยอมรับตามเกณฑ์เฉลี่ย (Early Majority)
- **ง.** กลุ่มล้าหลัง (Laggards)
- **จ.** กลุ่มต่อต้าน

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร กลุ่มผู้นำการเปลี่ยนแปลง / ยอมรับเร็ว (Early Adopters)

### ข้อที่ 304: กลุ่มผู้ยอมรับที่มีสัดส่วนมากที่สุดในประชากร (กลุ่มละ 34%)
- **ก.** Innovators และ Early Adopters
- **ข.** Early Majority และ Late Majority
- **ค.** Early Adopters และ Laggards
- **ง.** Innovators และ Laggards
- **จ.** กลุ่มผู้นำชุมชน

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Early Majority และ Late Majority

### ข้อที่ 305: ลักษณะของกลุ่มล้าหลัง (Laggards: 16%)
- **ก.** ชอบเสี่ยงภัยและมีฐานะร่ำรวย
- **ข.** เป็นผู้นำทางความคิดในหมู่บ้าน
- **ค.** ยึดติดกับประเพณีดั้งเดิม ระมัดระวังสูง ไม่ไว้ใจนวัตกรรมและเจ้าหน้าที่
- **ง.** ใช้เทคโนโลยีดิจิทัลเป็นประจำ
- **จ.** มีเครือข่ายกว้างขวางภายนอกชุมชน

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ยึดติดกับประเพณีดั้งเดิม ระมัดระวังสูง ไม่ไว้ใจนวัตกรรมและเจ้าหน้าที่

### ข้อที่ 306: Relative Advantage ในคุณลักษณะนวัตกรรมหมายถึง
- **ก.** ความเข้ากันได้กับประเพณี
- **ข.** ความซับซ้อนในการใช้งาน
- **ค.** การทดลองทำในแปลงเล็กได้
- **ง.** ความได้เปรียบเชิงเปรียบเทียบที่ดีกว่าวิธีเดิม (ลดต้นทุน เพิ่มกำไร)
- **จ.** การมองเห็นผลลัพธ์ด้วยตา

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ความได้เปรียบเชิงเปรียบเทียบที่ดีกว่าวิธีเดิม (ลดต้นทุน เพิ่มกำไร)

### ข้อที่ 307: Compatibility หมายถึงข้อใด
- **ก.** ความยากง่ายของเทคโนโลยี
- **ข.** ความสามารถในการแบ่งทดลอง
- **ค.** ความชัดเจนของผลผลิต
- **ง.** ผลตอบแทนทางเศรษฐกิจ
- **จ.** ความเข้ากันได้กับค่านิยม ประสบการณ์เดิม และวิถีชีวิตของเกษตรกร

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ความเข้ากันได้กับค่านิยม ประสบการณ์เดิม และวิถีชีวิตของเกษตรกร

### ข้อที่ 308: Trialability มีประโยชน์ต่องานส่งเสริมการเกษตรอย่างไร
- **ก.** ช่วยให้เกษตรกรสามารถทดลองทำในพื้นที่ขนาดเล็กได้ก่อนตัดสินใจลงทุนทั้งแปลง
- **ข.** ช่วยลดราคาปุ๋ยเคมี
- **ค.** ช่วยให้พืชโตเร็วขึ้นสองเท่า
- **ง.** ช่วยให้ไม่ต้องใช้แรงงานคน
- **จ.** ช่วยในการขอสินเชื่อธนาคาร

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ช่วยให้เกษตรกรสามารถทดลองทำในพื้นที่ขนาดเล็กได้ก่อนตัดสินใจลงทุนทั้งแปลง

### ข้อที่ 309: แบบจำลองการสื่อสาร SMCR พัฒนาโดยใคร
- **ก.** วิลเบอร์ ชแรมม์ (Wilbur Schramm)
- **ข.** เดวิด เค. เบอร์โล (David K. Berlo)
- **ค.** แชนนอนและวีเวอร์ (Shannon & Weaver)
- **ง.** ฮาโรลด์ ลาสเวลล์ (Harold Lasswell)
- **จ.** มาร์แชลล์ แมกลูฮัน (Marshall McLuhan)

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เดวิด เค. เบอร์โล (David K. Berlo)

### ข้อที่ 310: ตัว C ในแบบจำลอง SMCR หมายถึงสิ่งใด
- **ก.** Context บริบทสิ่งแวดล้อม
- **ข.** Control การควบคุมสาร
- **ค.** Channel ช่องทางการสื่อสารผ่านประสาทสัมผัสทั้งห้าและสื่อ
- **ง.** Coding การถอดรหัส
- **จ.** Cyber เครือข่ายดิจิทัล

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Channel ช่องทางการสื่อสารผ่านประสาทสัมผัสทั้งห้าและสื่อ

### ข้อที่ 311: ทฤษฎีการเรียนรู้ของผู้ใหญ่ (Andragogy) เสนอโดยใคร
- **ก.** จอห์น ดิวอี้ (John Dewey)
- **ข.** ฌอง เพียเจต์ (Jean Piaget)
- **ค.** บี.เอฟ. สกินเนอร์ (B.F. Skinner)
- **ง.** มัลคอล์ม โนว์ลส์ (Malcolm Knowles)
- **จ.** เลฟ วีกอตสกี (Lev Vygotsky)

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร มัลคอล์ม โนว์ลส์ (Malcolm Knowles)

### ข้อที่ 312: หลักการสำคัญของ Andragogy เกี่ยวกับแรงจูงใจในการเรียนรู้
- **ก.** ผู้ใหญ่เรียนเพื่อล่าเกรดและคะแนนสอบ
- **ข.** ผู้ใหญ่ต้องถูกลงโทษจึงจะตั้งใจเรียน
- **ค.** ผู้ใหญ่เรียนรู้เหมือนเด็กทุกประการ
- **ง.** ผู้ใหญ่ไม่สามารถเรียนรู้สิ่งใหม่ได้
- **จ.** ผู้ใหญ่ถูกขับเคลื่อนด้วยแรงจูงใจภายใน (ความภาคภูมิใจ ความต้องการพึ่งตนเอง)

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ผู้ใหญ่ถูกขับเคลื่อนด้วยแรงจูงใจภายใน (ความภาคภูมิใจ ความต้องการพึ่งตนเอง)

### ข้อที่ 313: ทฤษฎีการเรียนรู้ทางสังคม (Social Learning Theory) ของแบนดูราเน้นเรื่องใด
- **ก.** การเรียนรู้ผ่านการสังเกตและการเลียนแบบตัวแบบ (Modeling)
- **ข.** การให้รางวัลและการลงโทษแบบคลาสสิก
- **ค.** การถ่ายทอดทางพันธุกรรม
- **ง.** การเรียนรู้ผ่านการอ่านหนังสือคนเดียว
- **จ.** การสะกดจิต

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การเรียนรู้ผ่านการสังเกตและการเลียนแบบตัวแบบ (Modeling)

### ข้อที่ 314: บันไดแห่งการมีส่วนร่วมของอาร์นสไตน์ ขั้นที่มีอำนาจแท้จริง (Citizen Power)
- **ก.** Manipulation และ Therapy
- **ข.** Partnership, Delegated Power, Citizen Control
- **ค.** Informing และ Consultation
- **ง.** Placation และ Informing
- **จ.** Tokenism

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Partnership, Delegated Power, Citizen Control

### ข้อที่ 315: ขั้น Tokenism ในบันไดของอาร์นสไตน์มีลักษณะอย่างไร
- **ก.** การที่ประชาชนเป็นเจ้าของโครงการ 100%
- **ข.** การถูกชักใยบงการโดยสิ้นเชิง
- **ค.** การมีส่วนร่วมแต่เพียงรูปแบบ เช่น บอกกล่าว รับฟัง แต่ไม่มีอำนาจตัดสินใจจริง
- **ง.** การร่วมบริหารจัดการงบประมาณ
- **จ.** การปฏิเสธไม่ร่วมมือกับรัฐ

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การมีส่วนร่วมแต่เพียงรูปแบบ เช่น บอกกล่าว รับฟัง แต่ไม่มีอำนาจตัดสินใจจริง

### ข้อที่ 316: กฎการลดน้อยถอยลงของผลผลิต (Law of Diminishing Returns)
- **ก.** ผลผลิตจะเพิ่มขึ้นเป็นสองเท่าเสมอเมื่อใส่ปุ๋ยเพิ่ม
- **ข.** ต้นทุนคงที่จะลดลงเรื่อยๆ จนเป็นศูนย์
- **ค.** ราคาพืชผลจะลดลงตามฤดูกาล
- **ง.** เมื่อเพิ่มปัจจัยผันแปรถึงจุดหนึ่ง ผลผลิตส่วนเพิ่ม (MP) จะเริ่มลดลง
- **จ.** พื้นที่เพาะปลูกจะลดลงตามกาลเวลา

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เมื่อเพิ่มปัจจัยผันแปรถึงจุดหนึ่ง ผลผลิตส่วนเพิ่ม (MP) จะเริ่มลดลง

### ข้อที่ 317: จุดคุ้มทุนทางเศรษฐศาสตร์ในการใช้ปัจจัยการผลิต
- **ก.** จุดที่ได้ผลผลิตรวมสูงสุด (Max Yield)
- **ข.** จุดที่ไม่ต้องใส่ปุ๋ยเลย
- **ค.** จุดที่ต้นทุนคงที่ต่ำที่สุด
- **ง.** จุดที่ใช้แรงงานมากที่สุด
- **จ.** จุดที่รายได้ส่วนเพิ่มเท่ากับต้นทุนส่วนเพิ่ม (MR = MC)

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร จุดที่รายได้ส่วนเพิ่มเท่ากับต้นทุนส่วนเพิ่ม (MR = MC)

### ข้อที่ 318: ต้นทุนค่าเสียโอกาส (Opportunity Cost) ในฟาร์มหมายถึง
- **ก.** มูลค่าผลประโยชน์สูงสุดที่ต้องสูญเสียไปจากการเลือกทำกิจกรรมหนึ่งแทนอีกกิจกรรมหนึ่ง
- **ข.** ค่าใช้จ่ายในการซ่อมแซมเครื่องจักร
- **ค.** ดอกเบี้ยเงินกู้นอกระบบ
- **ง.** ค่าปรับจากการผิดสัญญา
- **จ.** เงินที่ทำหล่นหายในแปลง

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร มูลค่าผลประโยชน์สูงสุดที่ต้องสูญเสียไปจากการเลือกทำกิจกรรมหนึ่งแทนอีกกิจกรรมหนึ่ง

### ข้อที่ 319: พฤติกรรม Risk-Averse ของเกษตรกรรายย่อยส่งผลอย่างไร
- **ก.** ทำให้ชอบเล่นการพนัน
- **ข.** ทำให้ระมัดระวังสูงและไม่กล้าตัดสินใจยอมรับนวัตกรรมใหม่ที่ยังไม่แน่นอน
- **ค.** ทำให้กล้ากู้เงินเกินตัวมาลงทุน
- **ง.** ทำให้เปลี่ยนพืชที่ปลูกทุกปี
- **จ.** ทำให้ไม่ยอมขายผลผลิต

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ทำให้ระมัดระวังสูงและไม่กล้าตัดสินใจยอมรับนวัตกรรมใหม่ที่ยังไม่แน่นอน

### ข้อที่ 320: การวิจัยเชิงปฏิบัติการแบบมีส่วนร่วม (PAR) มีวงจรการทำงานอย่างไร
- **ก.** สั่งการ -> ปฏิบัติ -> ลงโทษ -> ปิดโครงการ
- **ข.** วิจัยในแล็บ -> ตีพิมพ์ -> สิ้นสุด
- **ค.** วางแผน (Plan) -> ปฏิบัติ (Act) -> สังเกต (Observe) -> สะท้อนคิด (Reflect)
- **ง.** แจกแบบสอบถาม -> ประมวลผล -> จบงาน
- **จ.** ตั้งสมมติฐาน -> ทดลอง -> ขายสิทธิบัตร

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร วางแผน (Plan) -> ปฏิบัติ (Act) -> สังเกต (Observe) -> สะท้อนคิด (Reflect)

# คลังข้อสอบประมวลสาระ หน่วยที่ 13: การส่งเสริมและพัฒนาการเกษตรในเขตเมือง ชานเมือง และชนบท (จำนวน 50 ข้อ)

### ข้อที่ 1301: ข้อใดอธิบายหลักการของ 'บทบาทของเกษตรในเขตเมือง (Urban Agriculture)' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **ง.** สร้างความมั่นคงทางอาหาร เพิ่มพื้นที่สีเขียว และบำบัดฟื้นฟูจิตใจคนเมือง
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร สร้างความมั่นคงทางอาหาร เพิ่มพื้นที่สีเขียว และบำบัดฟื้นฟูจิตใจคนเมือง

### ข้อที่ 1302: ข้อใดอธิบายหลักการของ 'โรงงานผลิตพืชระบบปิด (Plant Factory: PFAL)' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **ง.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง
- **จ.** การปลูกพืชในห้องควบคุมแสง LED อุณหภูมิ และธาตุอาหาร 100% ปลอดเชื้อ

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การปลูกพืชในห้องควบคุมแสง LED อุณหภูมิ และธาตุอาหาร 100% ปลอดเชื้อ

### ข้อที่ 1303: ข้อใดอธิบายหลักการของ 'ระบบอควาโปนิกส์ (Aquaponics)' ได้ถูกต้องที่สุด

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การเลี้ยงปลาร่วมกับการปลูกผักในระบบน้ำวนปิด มูลปลาเป็นปุ๋ยให้ผัก ผักกรองน้ำสะอาดให้ปลา

### ข้อที่ 1304: ข้อใดอธิบายหลักการของ 'ลักษณะเด่นของเกษตรชานเมือง (Peri-Urban)' ได้ถูกต้องที่สุด

- **ค.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที

### ข้อที่ 1305: ข้อใดอธิบายหลักการของ 'เกษตรชุมชนสนับสนุน (Community Supported Agriculture: CSA)' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** ผู้บริโภคจ่ายเงินล่วงหน้าเป็นสมาชิกรับกล่องผักปลอดภัยตามฤดูกาลร่วมแบ่งปันความเสี่ยง
- **ง.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ผู้บริโภคจ่ายเงินล่วงหน้าเป็นสมาชิกรับกล่องผักปลอดภัยตามฤดูกาลร่วมแบ่งปันความเสี่ยง

### ข้อที่ 1306: ข้อใดอธิบายหลักการของ 'ความท้าทายหลักของเกษตรกรรมชนบท (Rural)' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **ง.** สังคมสูงวัย ขาดแคลนแรงงานคนรุ่นใหม่ และการขาดแคลนระบบน้ำชลประทาน
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร สังคมสูงวัย ขาดแคลนแรงงานคนรุ่นใหม่ และการขาดแคลนระบบน้ำชลประทาน

### ข้อที่ 1307: ข้อใดอธิบายหลักการของ 'ห่วงโซ่อุปทานอาหารระยะสั้น (Short Food Supply Chain)' ได้ถูกต้องที่สุด

- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **ง.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง
- **จ.** การลดขั้นตอนคนกลาง เก็บเกี่ยวผลผลิตเช้าและส่งมอบถึงผู้บริโภคโดยตรงในบ่าย

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การลดขั้นตอนคนกลาง เก็บเกี่ยวผลผลิตเช้าและส่งมอบถึงผู้บริโภคโดยตรงในบ่าย

- **ก.** การปนเปื้อนโลหะหนักและฝุ่นควันไอเสียรถยนต์ ป้องกันด้วยการปลูกในโรงเรือนมุ้งตาข่าย

### ข้อที่ 1343: ข้อใดอธิบายหลักการของ 'ระบบอควาโปนิกส์ (Aquaponics)' ได้ถูกต้องที่สุด

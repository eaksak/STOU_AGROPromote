# คลังข้อสอบประมวลสาระ หน่วยที่ 04: แนวคิด ทฤษฎีเชิงพฤติกรรม การเรียนรู้และการเปลี่ยนแปลงในงานส่งเสริมและพัฒนาการเกษตร (จำนวน 50 ข้อ)

### ข้อที่ 401: โครงสร้างพฤติกรรมตามกรอบ K-A-P Model ประกอบด้วยอะไร
- **ก.** Key - Action - Plan
- **ข.** Kernel - Agri - Product
- **ค.** Know-how - Ability - Power
- **ง.** Kind - Active - Polite
- **จ.** Knowledge (ความรู้) - Attitude (ทัศนคติ) - Practice (การปฏิบัติ)

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Knowledge (ความรู้) - Attitude (ทัศนคติ) - Practice (การปฏิบัติ)

### ข้อที่ 402: องค์ประกอบใดใน KAP Model ที่เป็นตัวกำหนดทิศทางของพฤติกรรมและความตั้งใจ
- **ก.** Attitude (เจตคติหรือทัศนคติ)
- **ข.** Knowledge
- **ค.** Practice
- **ง.** Power
- **จ.** Policy

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Attitude (เจตคติหรือทัศนคติ)

### ข้อที่ 403: กระบวนการตัดสินใจยอมรับนวัตกรรม 5 ขั้นตอนของโรเจอร์ส ขั้นแรกสุดคือ
- **ก.** ขั้นจูงใจ (Persuasion)
- **ข.** ขั้นรับรู้ / มีความรู้ (Knowledge Stage)
- **ค.** ขั้นตัดสินใจ (Decision)
- **ง.** ขั้นปฏิบัติการ (Implementation)
- **จ.** ขั้นยืนยัน (Confirmation)

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ขั้นรับรู้ / มีความรู้ (Knowledge Stage)

### ข้อที่ 404: ขั้น Persuasion ในกระบวนการยอมรับนวัตกรรม เกษตรกรมีพฤติกรรมอย่างไร
- **ก.** เริ่มปลูกเต็มพื้นที่ 100 ไร่
- **ข.** ปฏิเสธไม่รับฟังข้อมูลใดๆ
- **ค.** เริ่มแสวงหาข้อมูลเพิ่มเติม ประเมินข้อดีข้อเสีย และสร้างทัศนคติเชิงบวก/ลบ
- **ง.** หยุดทำกิจกรรมการเกษตร
- **จ.** ยกฟาร์มให้ลูกหลานทำแทน

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เริ่มแสวงหาข้อมูลเพิ่มเติม ประเมินข้อดีข้อเสีย และสร้างทัศนคติเชิงบวก/ลบ

### ข้อที่ 405: ทฤษฎีพฤติกรรมตามแผน (Theory of Planned Behavior: TPB) พัฒนาโดยใคร
- **ก.** เคิร์ต เลวิน (Kurt Lewin)
- **ข.** เดวิด คอลบ์ (David Kolb)
- **ค.** มาร์ติน เซลิกแมน (Martin Seligman)
- **ง.** ไอเซก แอจเซน (Icek Ajzen)
- **จ.** คาร์ล โรเจอร์ส (Carl Rogers)

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ไอเซก แอจเซน (Icek Ajzen)

### ข้อที่ 406: Subjective Norms ในทฤษฎี TPB หมายถึงข้อใด
- **ก.** ความมั่นใจในความสามารถของตนเอง
- **ข.** ทัศนคติต่อผลประโยชน์ส่วนตัว
- **ค.** กฎหมายและระเบียบราชการ
- **ง.** สภาพดินฟ้าอากาศ
- **จ.** การรับรู้ถึงแรงกดดันทางสังคมรอบข้าง เช่น ครอบครัว เพื่อนบ้าน ผู้นำชุมชน

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การรับรู้ถึงแรงกดดันทางสังคมรอบข้าง เช่น ครอบครัว เพื่อนบ้าน ผู้นำชุมชน

### ข้อที่ 407: Perceived Behavioral Control (PBC) หมายถึง
- **ก.** การประเมินว่าตนเองมีความพร้อม ทักษะ ทุน เวลา และโอกาสในการทำพฤติกรรมนั้นได้สำเร็จ
- **ข.** การควบคุมอารมณ์ตนเอง
- **ค.** การบังคับให้ผู้อื่นทำตาม
- **ง.** การบริหารจัดการแรงงานในฟาร์ม
- **จ.** การควบคุมศัตรูพืชในแปลง

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การประเมินว่าตนเองมีความพร้อม ทักษะ ทุน เวลา และโอกาสในการทำพฤติกรรมนั้นได้สำเร็จ

### ข้อที่ 408: แบบจำลองการเปลี่ยนแปลง 3 ขั้นตอนของเคิร์ต เลวิน ประกอบด้วย
- **ก.** Planning -> Doing -> Checking
- **ข.** Unfreezing (ละลายพฤติกรรม) -> Changing (เปลี่ยนแปลง) -> Refreezing (ตรึงพฤติกรรมใหม่)
- **ค.** Start -> Process -> Stop
- **ง.** Forming -> Storming -> Norming
- **จ.** Input -> Process -> Output

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร Unfreezing (ละลายพฤติกรรม) -> Changing (เปลี่ยนแปลง) -> Refreezing (ตรึงพฤติกรรมใหม่)

### ข้อที่ 409: ขั้น Unfreezing ในงานส่งเสริมการเกษตรมีเป้าหมายเพื่ออะไร
- **ก.** การแช่แข็งผลผลิตเพื่อส่งออก
- **ข.** การฝึกทักษะการตัดแต่งกิ่ง
- **ค.** ทำให้เกษตรกรตระหนักถึงวิกฤตและความจำเป็นที่ต้องเลิกใช้วิธีเดิมที่ล้มเหลว
- **ง.** การมอบรางวัลเกษตรกรดีเด่น
- **จ.** การจัดทำสัญญาเงินกู้

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ทำให้เกษตรกรตระหนักถึงวิกฤตและความจำเป็นที่ต้องเลิกใช้วิธีเดิมที่ล้มเหลว

### ข้อที่ 410: ขั้น Refreezing ทำได้อย่างไรให้เกิดความยั่งยืน
- **ก.** การหยุดการติดต่อกับเกษตรกร
- **ข.** การตัดงบประมาณสนับสนุนทันที
- **ค.** การสั่งห้ามไม่ให้ปรับปรุงวิธีใหม่อีก
- **ง.** การเสริมแรงเชิงบวก การรับรองมาตรฐาน GAP และการสร้างตลาดรองรับที่มั่นคง
- **จ.** การย้ายเจ้าหน้าที่ส่งเสริมออกจากพื้นที่

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การเสริมแรงเชิงบวก การรับรองมาตรฐาน GAP และการสร้างตลาดรองรับที่มั่นคง

### ข้อที่ 411: สาเหตุสำคัญที่สุดที่ทำให้เกษตรกร 'ต่อต้านการเปลี่ยนแปลง' (Resistance to Change)
- **ก.** ความเกียจคร้านแต่กำเนิด
- **ข.** ความร่ำรวยจนไม่ต้องพึ่งพาใคร
- **ค.** การมีเทคโนโลยีที่ดีกว่าอยู่แล้ว
- **ง.** ความต้องการแกล้งเจ้าหน้าที่รัฐ
- **จ.** ความกลัวความไม่แน่นอนและความเสี่ยงที่อาจทำให้ผลผลิตลดลงและขาดรายได้

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ความกลัวความไม่แน่นอนและความเสี่ยงที่อาจทำให้ผลผลิตลดลงและขาดรายได้

### ข้อที่ 412: ลำดับขั้นความต้องการของมาสโลว์ ขั้นล่างสุดคือ
- **ก.** ความต้องการทางกายภาพและปัจจัยสี่ (Physiological Needs)
- **ข.** ความต้องการความปลอดภัย (Safety Needs)
- **ค.** ความต้องการความรักและความเป็นส่วนหนึ่ง (Social Needs)
- **ง.** ความต้องการการยกย่องนับถือ (Esteem Needs)
- **จ.** ความต้องการบรรลุศักยภาพสูงสุด (Self-Actualization)

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ความต้องการทางกายภาพและปัจจัยสี่ (Physiological Needs)

### ข้อที่ 413: เกษตรกรที่มุ่งเป็น 'ปราชญ์ชาวบ้าน' ถ่ายทอดความรู้แก่ผู้อื่นโดยไม่หวังสิ่งตอบแทน ตรงกับขั้นใดของมาสโลว์
- **ก.** ความต้องการทางกายภาพ
- **ข.** ความต้องการบรรลุศักยภาพสูงสุดของตน (Self-Actualization)
- **ค.** ความต้องการความปลอดภัย
- **ง.** ความต้องการเงินทอง
- **จ.** ความต้องการอำนาจ

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ความต้องการบรรลุศักยภาพสูงสุดของตน (Self-Actualization)

### ข้อที่ 414: Positive Reinforcement ในงานส่งเสริมการเกษตร
- **ก.** การหักเงินช่วยเหลือเมื่อทำผิด
- **ข.** การตำหนิต่อหน้าเพื่อนบ้าน
- **ค.** การชมเชย การมอบใบประกาศเกียรติคุณ หรือการพาไปศึกษาดูงานเมื่อเกษตรกรทำสำเร็จ
- **ง.** การบังคับให้อยู่เวรยาม
- **จ.** การขู่ว่าจะดำเนินคดี

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การชมเชย การมอบใบประกาศเกียรติคุณ หรือการพาไปศึกษาดูงานเมื่อเกษตรกรทำสำเร็จ

### ข้อที่ 415: วงจรการเรียนรู้จากประสบการณ์ (Experiential Learning Cycle) ของคอลบ์ มีกี่ขั้นตอน
- **ก.** 2 ขั้นตอน
- **ข.** 3 ขั้นตอน
- **ค.** 5 ขั้นตอน
- **ง.** 4 ขั้นตอน (Concrete Experience -> Reflective Observation -> Abstract Conceptualization -> Active Experimentation)
- **จ.** 7 ขั้นตอน

> **เฉลยข้อ ง**: คำตอบที่ถูกต้องคือข้อ ง เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร 4 ขั้นตอน (Concrete Experience -> Reflective Observation -> Abstract Conceptualization -> Active Experimentation)

### ข้อที่ 416: ขั้น Reflective Observation ในวงจรของคอลบ์ เกษตรกรทำกิจกรรมใด
- **ก.** ลงมือผสมปุ๋ยในถัง
- **ข.** อ่านตำราเคมีอินทรีย์
- **ค.** นำผลผลิตไปขายที่ตลาด
- **ง.** เขียนคำของบประมาณ
- **จ.** สังเกตผลที่เกิดขึ้นในแปลงและแลกเปลี่ยนสะท้อนคิดกับเพื่อนเกษตรกร

> **เฉลยข้อ จ**: คำตอบที่ถูกต้องคือข้อ จ เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร สังเกตผลที่เกิดขึ้นในแปลงและแลกเปลี่ยนสะท้อนคิดกับเพื่อนเกษตรกร

### ข้อที่ 417: โรงเรียนเกษตรกร (Farmer Field School: FFS) มีลักษณะการเรียนรู้อย่างไร
- **ก.** เน้นเกษตรกรเป็นศูนย์กลาง เรียนรู้ร่วมกันในแปลงตลอดฤดูกาลผลิตผ่านการวิเคราะห์ระบบนิเวศ (AESA)
- **ข.** การนั่งฟังบรรยายในห้องประชุมตลอด 5 วัน
- **ค.** การดูคลิปวิดีโอจากต่างประเทศ
- **ง.** การสอบข้อเขียนเพื่อรับวุฒิบัตร
- **จ.** การให้เจ้าหน้าที่ทำแทนทุกอย่าง

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เน้นเกษตรกรเป็นศูนย์กลาง เรียนรู้ร่วมกันในแปลงตลอดฤดูกาลผลิตผ่านการวิเคราะห์ระบบนิเวศ (AESA)

### ข้อที่ 418: คำกล่าวที่ว่า 'เกษตรกรเชื่อเกษตรกรด้วยกันมากที่สุด' มีนัยต่องานส่งเสริมอย่างไร
- **ก.** นักส่งเสริมไม่ต้องลงพื้นที่ทำงานอีกต่อไป
- **ข.** ควรใช้เกษตรกรต้นแบบและแปลงสาธิตของเพื่อนบ้านเป็นสื่อหลักในการจูงใจ
- **ค.** ห้ามไม่ให้นักวิชาการพูดคุยกับเกษตรกร
- **ง.** ให้เกษตรกรเรียนรู้กันเองโดยไม่ต้องมีข้อมูลวิชาการ
- **จ.** ยกเลิกหน่วยงานส่งเสริมการเกษตร

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ควรใช้เกษตรกรต้นแบบและแปลงสาธิตของเพื่อนบ้านเป็นสื่อหลักในการจูงใจ

### ข้อที่ 419: การให้ข้อมูลป้อนกลับทันที (Immediate Feedback) ช่วยเกษตรกรอย่างไร
- **ก.** ช่วยประหยัดค่าโทรศัพท์
- **ข.** ช่วยให้พืชออกผลเร็วกว่ากำหนด
- **ค.** ช่วยให้ทราบผลการตรวจดินหรือโรคพืชอย่างรวดเร็ว ทำให้เกิดความมั่นใจและแก้ไขได้ทันที
- **ง.** ช่วยลดราคาปุ๋ยเคมี
- **จ.** ช่วยให้ได้เงินอุดหนุนเร็วขึ้น

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ช่วยให้ทราบผลการตรวจดินหรือโรคพืชอย่างรวดเร็ว ทำให้เกิดความมั่นใจและแก้ไขได้ทันที

### ข้อที่ 420: การสะท้อนคิด (Reflection) ในกระบวนการเรียนรู้ช่วยให้เกิดสิ่งใด
- **ก.** การเกิดความขัดแย้งในกลุ่ม
- **ข.** การทำให้เสียเวลาทำงานในแปลง
- **ค.** การลืมความรู้เดิมทั้งหมด

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร เน้นเกษตรกรเป็นศูนย์กลาง เรียนรู้ร่วมกันในแปลงตลอดฤดูกาลผลิตผ่านการวิเคราะห์ระบบนิเวศ (AESA)

### ข้อที่ 438: [การประยุกต์ใช้] ในการดำเนินงานส่งเสริมและพัฒนาการเกษตร คำกล่าวที่ว่า 'เกษตรกรเชื่อเกษตรกรด้วยกันมากที่สุด' มีนัยต่องานส่งเสริมอย่างไร
- **ก.** นักส่งเสริมไม่ต้องลงพื้นที่ทำงานอีกต่อไป
- **ข.** ควรใช้เกษตรกรต้นแบบและแปลงสาธิตของเพื่อนบ้านเป็นสื่อหลักในการจูงใจ
- **ค.** ห้ามไม่ให้นักวิชาการพูดคุยกับเกษตรกร
- **ง.** ให้เกษตรกรเรียนรู้กันเองโดยไม่ต้องมีข้อมูลวิชาการ
- **จ.** ยกเลิกหน่วยงานส่งเสริมการเกษตร

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ควรใช้เกษตรกรต้นแบบและแปลงสาธิตของเพื่อนบ้านเป็นสื่อหลักในการจูงใจ

### ข้อที่ 439: [การประยุกต์ใช้] ในการดำเนินงานส่งเสริมและพัฒนาการเกษตร การให้ข้อมูลป้อนกลับทันที (Immediate Feedback) ช่วยเกษตรกรอย่างไร
- **ก.** ช่วยประหยัดค่าโทรศัพท์
- **ข.** ช่วยให้พืชออกผลเร็วกว่ากำหนด

- **ง.** ช่วยลดราคาปุ๋ยเคมี
- **จ.** ช่วยให้ได้เงินอุดหนุนเร็วขึ้น

### ข้อที่ 440: [การประยุกต์ใช้] ในการดำเนินงานส่งเสริมและพัฒนาการเกษตร การสะท้อนคิด (Reflection) ในกระบวนการเรียนรู้ช่วยให้เกิดสิ่งใด

### ข้อที่ 444: [การวิเคราะห์เชิงนโยบาย] ปัจจัยสำคัญที่เกี่ยวข้องกับ ขั้น Persuasion ในกระบวนการยอมรับนวัตกรรม เกษตรกรมีพฤติกรรมอย่างไร

# คลังข้อสอบประมวลสาระ หน่วยที่ 15: การนิเทศ การติดตามและการประเมินในการส่งเสริมและพัฒนาการเกษตร (จำนวน 50 ข้อ)

### ข้อที่ 1501: ข้อใดอธิบายหลักการของ 'ปรัชญาของการนิเทศงานส่งเสริมการเกษตรยุคใหม่' ได้ถูกต้องที่สุด
- **ก.** การสร้างสัมพันธภาพเชิงเกื้อหนุนและพัฒนาสมรรถนะ (ไม่ใช่การจับผิด)
- **ข.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ค.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ง.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ก**: คำตอบที่ถูกต้องคือข้อ ก เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การสร้างสัมพันธภาพเชิงเกื้อหนุนและพัฒนาสมรรถนะ (ไม่ใช่การจับผิด)

### ข้อที่ 1502: ข้อใดอธิบายหลักการของ 'หน้าที่ 3 ด้านของการนิเทศงาน' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบริหารจัดการ (Administrative), การพัฒนาการศึกษา (Educational), และการสนับสนุนจิตใจ (Supportive)
- **ค.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ง.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ข**: คำตอบที่ถูกต้องคือข้อ ข เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร การบริหารจัดการ (Administrative), การพัฒนาการศึกษา (Educational), และการสนับสนุนจิตใจ (Supportive)

### ข้อที่ 1503: ข้อใดอธิบายหลักการของ 'วัตถุประสงค์หลักของการติดตามงาน (Monitoring)' ได้ถูกต้องที่สุด
- **ก.** การยกเลิกการดำเนินงานเพื่อประหยัดงบประมาณ
- **ข.** การบังคับใช้กฎหมายลงโทษเกษตรกรทันที
- **ค.** ตรวจสอบความก้าวหน้าของกิจกรรม ปัจจัยนำเข้า และผลผลิตตามแผนเพื่อแก้ไขปัญหาทันเวลา
- **ง.** การห้ามเกษตรกรรายย่อยมีส่วนร่วม
- **จ.** การดำเนินการเฉพาะในห้องทดลองส่วนกลาง

> **เฉลยข้อ ค**: คำตอบที่ถูกต้องคือข้อ ค เนื่องจากตามหลักวิชาการส่งเสริมการเกษตร ตรวจสอบความก้าวหน้าของกิจกรรม ปัจจัยนำเข้า และผลผลิตตามแผนเพื่อแก้ไขปัญหาทันเวลา

### ข้อที่ 1504: ข้อใดอธิบายหลักการของ 'ความแตกต่างระหว่างการติดตามกับการประเมินผล' ได้ถูกต้องที่สุด

- **ง.** การติดตามทำต่อเนื่องดู Inputs/Outputs ส่วนการประเมินผลทำเป็นระยะดู Outcomes/Impact

# หน่วยที่ 4: แนวคิด ทฤษฎีเชิงพฤติกรรม การเรียนรู้และการเปลี่ยนแปลงในงานส่งเสริมและพัฒนาการเกษตร

## 1. แนวคิดเกี่ยวกับพฤติกรรมและการเปลี่ยนแปลงพฤติกรรมของเกษตรกร

### 1.1 โครงสร้างพฤติกรรมมนุษย์ (K-A-P Model)
พฤติกรรม (Behavior) ของเกษตรกรในการทำการเกษตรประกอบด้วย 3 มิติหลักที่เชื่อมโยงสัมพันธ์กัน:
1. **ความรู้ (Knowledge - K)**:
   - ความเข้าใจ การรับรู้ข้อมูล ข้อเท็จจริง หลักวิชาการ และขั้นตอนปฏิบัติทางการเกษตร
   - ถือเป็นด่านแรกของการเปลี่ยนแปลง แต่ความรู้เพียงอย่างเดียวไม่เพียงพอที่จะทำให้เกิดการกระทำ
2. **เจตคติหรือทัศนคติ (Attitude - A)**:
   - ความรู้สึก ความเชื่อ ความชอบ หรือความไม่ชอบ ความรู้สึกเห็นคุณค่าต่อวิธีการหรือนวัตกรรมนั้น
   - เป็นตัวกำหนดทิศทางของพฤติกรรม หากเกษตรกรมีทัศนคติเป็นลบ (เช่น เชื่อว่าไม่ฉีดยาเคมีจะไม่มีผลผลิต) ย่อมไม่เกิดการเปลี่ยนแปลง
3. **การปฏิบัติหรือทักษะ (Practice / Skill - P)**:
   - การลงมือทำจริง ความชำนาญ และความคล่องแคล่วในการนำความรู้ไปใช้ในแปลง
   - การเปลี่ยนแปลงที่ยั่งยืนต้องทำให้เกิดการยอมรับและปฏิบัติจนเป็นวิถีชีวิตปกติ (Adoption & Habitual Practice)

### 1.2 กระบวนการตัดสินใจยอมรับนวัตกรรม 5 ขั้นตอน (Innovation-Decision Process)
ตามแนวคิดของโรเจอร์ส เกษตรกรจะผ่านกระบวนการทางจิตวิทยา 5 ขั้นตอนก่อนตัดสินใจยอมรับสิ่งใหม่:
1. **ขั้นรับรู้ / มีความรู้ (Knowledge Stage)**: เกษตรกรสัมผัสหรือรับทราบเป็นครั้งแรกว่ามีนวัตกรรมนี้อยู่ แต่ยังไม่มีข้อมูลละเอียด
2. **ขั้นจูงใจ / สนใจ (Persuasion Stage)**: เกษตรกรเริ่มแสวงหาข้อมูลเพิ่มเติม ประเมินข้อดีข้อเสีย และเริ่มสร้างทัศนคติเชิงบวกหรือเชิงลบ
3. **ขั้นตัดสินใจ (Decision Stage)**: เกษตรกรเลือกที่จะทดลองปฏิบัติหรือไม่ทดลองทำ โดยมักเริ่มต้นจากการทดลองในขนาดเล็ก
4. **ขั้นปฏิบัติการ (Implementation Stage)**: นำนวัตกรรมไปใช้งานจริงในแปลง อาจพบปัญหาอุปสรรคเชิงเทคนิคที่ต้องขอคำปรึกษา
5. **ขั้นยืนยันการยอมรับ (Confirmation Stage)**: ประเมินผลลัพธ์ที่ได้ หากพึงพอใจจะตัดสินใจใช้ต่อไปเป็นประจำ แต่หากไม่คุ้มค่าหรือเกิดผลเสีย อาจยุติการใช้ (Discontinuance)

## 2. ทฤษฎีพฤติกรรมตามแผนและเหตุผล (Theory of Planned Behavior: TPB)

พัฒนาขึ้นโดย **ไอเซก แอจเซน (Icek Ajzen)** เพื่ออธิบายปัจจัยที่มีอิทธิพลต่อความตั้งใจเชิงพฤติกรรม (Behavioral Intention) ก่อนนำไปสู่การกระทำจริง ประกอบด้วย 3 องค์ประกอบหลัก:

1. **เจตคติต่อพฤติกรรม (Attitude toward the Behavior)**:
   - เกษตรกรประเมินว่า การทำพฤติกรรมนั้น (เช่น การทำเกษตรอินทรีย์) จะนำไปสู่ผลลัพธ์ที่ดีหรือแย่ต่อชีวิตตนเอง
2. **การคล้อยตามบรรทัดฐานของกลุ่มอ้างอิง (Subjective Norms)**:
   - การรับรู้ถึงแรงกดดันทางสังคมรอบข้าง เช่น ครอบครัว เพื่อนบ้าน ผู้นำชุมชน ว่าพวกเขาเห็นชอบหรือคัดค้านต่อพฤติกรรมนั้น
3. **การรับรู้ความสามารถในการควบคุมพฤติกรรม (Perceived Behavioral Control: PBC)**:
   - เกษตรกรประเมินว่าตนเองมีความพร้อม ทักษะ ทุน เวลา และโอกาสในการทำพฤติกรรมนั้นได้สำเร็จเพียงใด
   - แม้เกษตรกรอยากทำเกษตรอินทรีย์ (Attitude ดี) และครอบครัวสนับสนุน (Norms ดี) แต่ถ้าขาดตลาดรับซื้อหรือขาดแรงงาน (PBC ต่ำ) เกษตรกรก็จะไม่ตัดสินใจทำ

## 3. ทฤษฎีการเปลี่ยนแปลงและการต่อต้านการเปลี่ยนแปลง

### 3.1 แบบจำลองการเปลี่ยนแปลง 3 ขั้นตอนของเคิร์ต เลวิน (Kurt Lewin's Force-Field Analysis)
การเปลี่ยนแปลงในชุมชนเกษตรกรเป็นการต่อสู้ระหว่างสองแรง:
- **แรงขับดัน (Driving Forces)**: สิ่งที่ผลักดันให้เกิดการเปลี่ยนแปลง เช่น ต้นทุนสารเคมีสูงขึ้น ราคาสินค้าเกษตรตกต่ำ นโยบายอุดหนุนของรัฐ
- **แรงต้านทาน (Restraining Forces)**: สิ่งที่ขัดขวางการเปลี่ยนแปลง เช่น ความคุ้นเคยกับวิธีเดิม ความกลัวความล้มเหลว หนี้สิน ขาดความรู้

#### ขั้นตอนการเปลี่ยนแปลง 3 ขั้น:
1. **ขั้นละลายพฤติกรรมเดิม (Unfreezing)**: ทำลายความเคยชินเดิม ทำให้เกษตรกรตระหนักว่าวิธีดั้งเดิมไม่สามารถตอบโจทย์ได้อีกต่อไป ชี้ให้เห็นวิกฤตและความจำเป็นต้องเปลี่ยน
2. **ขั้นการเปลี่ยนแปลงสู่สิ่งใหม่ (Changing / Moving)**: แนะนำแนวคิด เทคโนโลยี และวิธีการใหม่ ฝึกอบรม สนับสนุนปัจจัยการผลิต และให้คำปรึกษาอย่างใกล้ชิด
3. **ขั้นตรึงพฤติกรรมใหม่ให้มั่นคง (Refreezing)**: เสริมแรงเชิงบวก (Positive Reinforcement) เช่น การยกย่องเชิดชูเกียรติ การรับรองมาตรฐาน การหาช่องทางตลาด เพื่อให้พฤติกรรมใหม่กลายเป็นบรรทัดฐานถาวร

### 3.2 สาเหตุของการต่อต้านการเปลี่ยนแปลงของเกษตรกร (Resistance to Change)
1. **ความกลัวความไม่แน่นอนและความเสี่ยง (Fear of Unknown & Risk)**: กังวลว่าผลผลิตจะลดลงและครอบครัวจะขาดรายได้
2. **ต้นทุนการเปลี่ยนผ่าน (Switching Costs)**: ต้องลงทุนซื้อเครื่องมือใหม่ ปรับปรุงดิน หรือเสียเวลาเรียนรู้
3. **ความผูกพันทางวัฒนธรรมและความเชื่อ (Cultural Attachment)**: วิธีเดิมเป็นสิ่งที่ทำตามบรรพบุรุษ มีความหมายทางจิตวิญญาณ
4. **ความไม่ไว้วางใจในตัวผู้ส่งเสริม (Distrust in Change Agents)**: เคยมีประสบการณ์ล้มเหลวจากโครงการรัฐในอดีต

## 4. จิตวิทยาการจูงใจและการเสริมแรงในงานส่งเสริมการเกษตร

### 4.1 ทฤษฎีลำดับขั้นความต้องการของมาสโลว์ (Maslow's Hierarchy of Needs)
การกระตุ้นให้เกษตรกรเปลี่ยนแปลง ต้องสอดคล้องกับระดับความต้องการของพวกเขา:
1. **ความต้องการทางกายภาพ (Physiological Needs)**: ข้าวปลาอาหาร รายได้พื้นฐานเพื่อการยังชีพ
2. **ความต้องการความมั่นคงปลอดภัย (Safety Needs)**: ความมั่นคงในที่ดินทำกิน การไม่มีหนี้สินล้นพ้นตัว ความปลอดภัยจากสารพิษ
3. **ความต้องการความรักและความเป็นส่วนหนึ่ง (Social Needs)**: การได้รับการยอมรับในกลุ่มเกษตรกรและชุมชน
4. **ความต้องการการยกย่องนับถือ (Esteem Needs)**: การได้รับรางวัลเกษตรกรดีเด่น การได้รับแต่งตั้งเป็นวิทยากรเกษตรกร
5. **ความต้องการบรรลุศักยภาพสูงสุดของตน (Self-Actualization)**: การเป็นปราชญ์ชาวบ้านที่อุทิศตนถ่ายทอดความรู้แก่ผู้อื่นโดยไม่หวังผลตอบแทน

### 4.2 หลักการเสริมแรง (Reinforcement Principle)
- **การเสริมแรงทางบวก (Positive Reinforcement)**: การให้รางวัล การชมเชย การพาไปทัศนศึกษาดูงาน เมื่อเกษตรกรทำสำเร็จ ช่วยเพิ่มความถี่ในการปฏิบัติดี
- **การให้ข้อมูลย้อนกลับทันที (Immediate Feedback)**: เมื่อเกษตรกรทดลองทำ ต้องแจ้งผลการวิเคราะห์ดินหรือคุณภาพผลผลิตให้ทราบโดยเร็ว เพื่อให้เกิดความมั่นใจ

## 5. กระบวนการเรียนรู้จากประสบการณ์ (Experiential Learning Theory)

พัฒนาโดย **เดวิด เอ. คอลบ์ (David A. Kolb)** โดยเน้นว่าการเรียนรู้ที่มีประสิทธิภาพสูงสุดของเกษตรกรเกิดจากวงจร 4 ขั้นตอน:
```
         [ 1. ประสบการณ์รูปธรรม (Concrete Experience) ]
                           │
                           ▼
         [ 2. การสังเกตและสะท้อนคิด (Reflective Observation) ]
                           │
                           ▼
         [ 3. การสร้างมโนทัศน์นามธรรม (Abstract Conceptualization) ]
                           │
                           ▼
         [ 4. การทดลองปฏิบัติการเชิงรุก (Active Experimentation) ]
                           │
                           └──────── (วนกลับสู่ขั้นที่ 1)
```

1. **Concrete Experience**: ให้เกษตรกรลงมือทำจริงในแปลง เช่น การหมักปุ๋ยชีวภาพ
2. **Reflective Observation**: ให้สังเกตการเปลี่ยนแปลง (อุณหภูมิกองปุ๋ย กลิ่น สี) และแลกเปลี่ยนสิ่งที่พบกับเพื่อนเกษตรกร
3. **Abstract Conceptualization**: สรุปเชื่อมโยงกับหลักวิชาการว่า เหตุใดปุ๋ยจึงร้อน จุลินทรีย์ทำงานอย่างไร ปุ๋ยช่วยบำรุงดินอย่างไร
4. **Active Experimentation**: เกษตรกรนำสูตรปุ๋ยไปปรับใช้ในแปลงของตนเองตามสภาพความพร้อม

## 6. แนวทางการขับเคลื่อนการเปลี่ยนแปลงพฤติกรรมในงานส่งเสริมการเกษตร

1. **การใช้แบบอย่างและกรณีศึกษาความสำเร็จ (Role Models & Success Stories)**: นำเกษตรกรไปดูงานแปลงของเกษตรกรต้นแบบที่เริ่มต้นจากศูนย์และประสบความสำเร็จ เพราะ "เกษตรกรเชื่อเกษตรกรด้วยกันมากที่สุด"
2. **การจัดกระบวนการโรงเรียนเกษตรกร (Farmer Field School: FFS)**: การเรียนรู้ร่วมกันตลอดฤดูกาลปลูก การวิเคราะห์ระบบนิเวศในแปลง (Agro-Ecosystem Analysis: AESA) ส่งเสริมให้เกษตรกรกลายเป็นนักวิจัยในแปลงตนเอง
3. **การออกแบบทางเลือกที่ลดความเสี่ยง (Nudge & Risk-Reduction Schemes)**: การสนับสนุนปัจจัยการผลิตเริ่มต้นบางส่วน การสร้างตลาดรองรับที่แน่นอน จะช่วยลดแรงต้านทานทางจิตวิทยาและกระตุ้นการตัดสินใจเปลี่ยนแปลงได้อย่างมีประสิทธิภาพ
